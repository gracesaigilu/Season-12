# Accessibility Audit Report

## Issues Found

1. Images did not have alternative text.
2. The HTML page needed a language attribute.
3. Heading structure was checked to ensure proper hierarchy.
4. Navigation links were checked to ensure they were descriptive.
5. Form inputs were checked to ensure they had associated labels.

## How I Fixed Them

- Added descriptive `alt` text to all images.
- Added `lang="en"` to the `<html>` tag.
- Used a proper heading hierarchy with `<h1>` and `<h2>`.
- Used descriptive navigation link text such as Home, About, Projects, Gallery, and Contact.
- Added labels associated with the form inputs.

## Final Lighthouse Accessibility Score

The final Lighthouse accessibility score is 100/100
